# كتاب أركان التفاعلي الذكي

هذا المستودع مخصص لمشروع **كتاب أركان التفاعلي**، بما في ذلك واجهة «ناقش معلمك أركان الذكي» في جميع أنواع الأسئلة.

## حالة الرفع
تم إنشاء المستودع والتحقق من الوصول إليه. **ملفات التطبيق الكاملة لم تُرفع بعد**؛ يرجى عدم اعتبار هذا المستودع نسخة جاهزة للتشغيل.

## الأمان
- لا ترفع أي مفتاح OpenAI أو ملفات `.env` تحتوي على أسرار.
- استخدم `OPENAI_API_KEY` كمتغير بيئة سري على الخادم.
- تشغيل المعلم الذكي الهجين يحتاج إعداد الواجهة الخلفية واختبارها قبل النشر للطلاب.

## مصدر المشروع
آخر حزمة عمل: `arkan-hybrid-all-questions.zip`، متاحة ضمن محادثة ChatGPT الأصلية؛ لم يتم رفع محتواها كاملًا إلى المستودع بعد.
